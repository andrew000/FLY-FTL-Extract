## 6. Encoder proxy: separability of the odours themselves (no brain)

`scripts/encoder_proxy.py`: logistic regression (the same `dan_update`, lr 0.5, L2 1e-05, early stopping on val F1) on the odours of the `grammar-3` dataset seed 20240914 — the same corpus, balance and 80/10/10 split as in `make_dataset.py` (train 225892, val 28235, test 28465 rows, 7099 positive in test). For the temporal encoder the features are the concatenation of the slot vectors (10 × 124), for fly-odor-3 its single vector. This is an upper bound for any readout after the noisy brain: information destroyed by the hash cannot come back. The reviewer's target: test F1 ≥ 0.996 before the brain is run.

The residual errors of the best variant (`docs/proxy_errors/keys_4.json`): 13 of ~20 are `obj.self.i18n.get("k", …)` (teacher: not a key, because the root is `obj`). The `.` token before `<PREFIX>` sits at distance −7, i.e. outside the slots, but enters the bigram of slot −6 (`. <PREFIX>`), so the information is in the odour; a linear readout over 124 buckets with 2 hashes does not separate it (1024 buckets give the same F1 0.9985 — the limit is not the hash but the linearity). This is the encoder's ceiling, which a brain with non-linear KCs can only preserve, not raise.

## 7. Temporal coding (reviewer's decision after Phase 5)

Window 6 / candidate / 3 → 10 slots, every slot its own 124-PN vector (encoder `fly-odor-4`: token + role — signed distance, type, bracket depth, bigram with the previous token; 2 hashes per feature; an empty slot is a zero vector). The brain receives the slots one after another, 20 ms each with no silence between puffs (`Brain.simulate_sequence`), 10 ms of silence at the end; the membrane state is not reset between puffs. Readout features — `[spiked, log1p(count)]` per puff: 2 × 10 × 2597 = 51940.

### Proxy

Logistic regression on the odours themselves, test split grammar-3: fly-odor-3 F1 0.9870 → fly-odor-4 F1 0.9985 (P 0.9971, R 0.9999); the target ≥ 0.996 is met. The full table is in §6.

### Sparsity per puff

Calibration on the real fixture candidates (`scripts/calibrate.py`, docs/BENCH.md §2): syn_scale = 10.0, apl_scale = 0.3 → 0.092 active KCs per non-empty puff (0.279 without APL); APL 6.4 spikes per puff. With a single `syn_scale` (apl_scale = 1) the per-puff activity never exceeded 1.6 % — APL fired at its refractory limit and silenced everything after the first puff; hence the second calibrated parameter (a deviation from PLAN, see BENCH.md §2).
