## 3. Selection

- Hemisphere: KCs by side — left 2580, right 2597 → **right**.
- APL: the `MBIN` class holds `APL` and `DPM`, one per side → exactly 1 APL in the chosen hemisphere.
- Groups (only `side == "right"`):

| group | rule | n |
|---|---|---:|
| PN | `cell_class == ALPN`, `cell_sub_class == uniglomerular`, transmitter acetylcholine | 124 |
| KC | `cell_class == Kenyon_Cell` (all subclasses) | 2597 |
| APL | `cell_type == APL` | 1 |
| MBON | `cell_class == MBON` | 48 |
| DAN | `cell_class == DAN` | 165 |
| total | | 2935 |

There are 139 uniglomerular ALPNs on this side; 15 of them are GABAergic (iPNs of the
mediolateral tract) and **excluded**: in the first run without this filter three such PNs had
≥ 5 synapses onto KCs and gave negative PN→KC weights, contradicting the sanity rule «PN→KC
only positive» (the excitatory input to the calyx is cholinergic).
This is a deviation from PLAN («uniglomerular ALPN» without a transmitter qualifier).

Every selected `root_id` is present in `proofread_root_ids_783.npy` (checked by the script and a test).

## 4. Transmitters and sign

`top_nt` (the predictor) gives **`dopamine` for all 2597 KCs**, whereas `known_nt`
(literature) gives `acetylcholine`. Hence the sign is taken as follows: the first classical
transmitter from `known_nt` (the `*-negative` tokens and co-transmitters such as `sNPF`,
`nitric oxide` are skipped), and if `known_nt` is empty — `top_nt`. The sign table:
ACh → +1, GABA → −1, glutamate → −1, dopamine/octopamine/serotonin → 0.
